# CRUD Operations - ASP.NET Core MVC

Employee management web app built with ASP.NET Core MVC and Entity Framework Core.

## Features
- Create, read, update, and delete employees
- Profile image upload
- Custom server-side validation (email must end with .com and be unique, strong password rules)
- Responsive admin dashboard layout (Bootstrap 5)

## Tech Stack
C#, ASP.NET Core MVC, Entity Framework Core, LINQ, SQL Server, Bootstrap 5, Razor

## Getting Started
1. Clone the repository
2. Update the connection string in `appsettings.json`
3. Run `Update-Database` in the Package Manager Console
4. Run the project
